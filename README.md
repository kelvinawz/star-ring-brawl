# 星环乱斗 · 离线动作格斗 Demo

原创 Q 版俯视角格斗试玩版。选择 4 名二次元少女斗士、4 件装备与 2 张擂台之一，单人挑战 3 名 AI 对手。角色由程序生成的三维多边形模型构成，包含体积化的头发、面部、衣装和动态四肢；场景采用俯视立体投影、分面光照和环境细节。游戏不依赖网络、账号或第三方脚本。

## 游玩

- 浏览器：[在线试玩](https://kelvinawz.github.io/star-ring-brawl/)；也可以直接打开 [index.html](index.html) 离线运行。
- macOS Apple Silicon：从 [v0.2.0 发行页](https://github.com/kelvinawz/star-ring-brawl/releases/tag/v0.2.0)下载 DMG，打开后把“星环乱斗.app”拖入“应用程序”。本地构建产物保存在 `dist/`。

当前 `.dmg` 采用临时签名，未进行 Developer ID 签名或 Apple 公证；从 GitHub 下载时 macOS 可能要求在“系统设置 → 隐私与安全性”中确认打开。正式公开分发应使用开发者证书签名并公证。

## 默认键盘操作

| 按键 | 动作 |
| --- | --- |
| 方向键 ↑↓←→ | 按住走路；同方向快速连按两下并按住跑动 |
| C | 三段轻连击；手持地面道具时挥击 |
| X | 重击；靠近道具时拾取；手持道具时丢弃 |
| V | 跳跃；轻点小跳，按住大跳 |
| Z | 瞄准；方向键调整方向，无方向输入时自动面向最近对手 |
| XC | 地面原地防御；跑动或空中时释放装备特殊招式，消耗 MP |
| ZXC | 星环必杀，消耗 75 MP |
| 跑 C / 跑 X | 冲刺轻攻 / 冲刺重击 |
| 跳 C / 跳 X | 空中轻攻 / 空中重击 |
| ZC / ZX | 瞄准轻技能 / 瞄准重技能，消耗 MP |
| Esc | 暂停 / 继续 |

**连按判定**：方向键第二次按下须在第一次松开后的约 0.28 秒内。C/X 单键有 0.075 秒组合键判定窗口；若两键在窗口内一起按，优先识别 XC。ZXC 在 XC 基础上按住 Z。

## 内容

- 斗士：银发双马尾信使闪闪、金发拳手团团、紫发术师墨墨、红发格斗家阿焰；各有速度、血量、伤害和被动差异。
- 装备：彗星拳套、泡泡发射器、雷鸣陀螺、星轨回旋镖。
- 地图：霓虹天台、暮雨站台；包含设备箱、护边、排水与警戒设施，仍可将对手击飞出界。
- 90 秒内击倒或淘汰全部对手获胜。

## macOS 构建

在装有 Apple Command Line Tools 的 Apple Silicon Mac 上运行：

```sh
./macos/build-dmg.sh
```

脚本使用系统 Cocoa/WebKit 编译本地应用，并生成、校验 `.dmg`。不需要 Electron、Node 或联网依赖。
